# Codex Android

A starter Android app using Kotlin and Jetpack Compose. Open this folder in Android Studio to sync and run the `app` configuration.

## Project skills

Android project skills are installed under `.agents/skills/`. They cover Compose UI, module structure, data layer, MVI presentation, navigation, Koin DI, error handling, and testing. Read the relevant `SKILL.md` before adding features.

## App identity

The starter application uses `com.example.codex`; change the namespace and application ID before publishing.
